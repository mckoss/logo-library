<logo-worksheet>

A worksheet: each row is a turtle program beside an empty box to draw what it makes. Check draws the answer in the box. The boxes are in the markup, so a printed page has them. Like <logo-example>, it's defined by the lessons entry. This page's markup:

<logo-worksheet>
<pre>repeat 3 [fd 100 rt 120]</pre><div class="logo-box" aria-label="Space to draw the shape"></div>
<pre data-check="house 80">to house :size
  repeat 4 [fd :size rt 90]
  fd :size rt 30
  repeat 3 [fd :size rt 120]
end</pre><div class="logo-box" aria-label="Space to draw the shape"></div>
</logo-worksheet>

A row's data-check is a command Check runs after the row's definitions. The host styles the rows and boxes (this page's styles, in its <head>, put them side by side). See CONTRACT.md.
