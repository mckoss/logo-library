logo-library

@mckoss/logo-library puts Logo in a web page as five custom elements: runnable, editable programs for lessons, worksheets, the Logo Playground, the language reference, and Turtle Tiles (Logo for little ones, with picture tiles). A page installs the package, serves its dist/ folder, and writes the elements' tags; the turtle, the music player and the reference come with it. It runs Logo with jslogo by Joshua Bell.

Version

Examples

Each page shows its markup and the element working. They're plain HTML: see their source.

  • <logo-example>: a program to edit and run
  • <logo-worksheet>: programs beside boxes to draw what they make
  • <logo-playground>: the Logo Playground
  • <logo-reference>: the language reference
  • <turtle-tiles>: Turtle Tiles, full screen
  • The music player: the notes and instruments every program can play
