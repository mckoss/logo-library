<logo-playground>

The whole Logo Playground: programs saved in the browser, an editor, Play, Step and the debugger, the stage, a command line, and the language reference. Its Examples folder comes from the JSON inside it. The playground entry defines it, and Open in Playground on the other pages lands here. This page's markup:

<logo-playground>
<script type="application/json" class="pg-examples-data">
[{"lesson": "Shapes", "url": "../example/", "examples": [
  {"name": "Square", "auto": false, "code": "to square :size\n  repeat 4 [fd :size rt 90]\nend", "run": "square 100"},
  {"name": "Star", "auto": false, "code": "repeat 5 [fd 150 rt 144]", "run": null}]},
 {"lesson": "Patterns", "url": "../worksheet/", "examples": [
  {"name": "Spiral", "auto": false, "code": "repeat 90 [fd repcount * 2 rt 89]", "run": null}]}]
</script>
</logo-playground>

Each lesson has a title and a page (its link in the folder); each example a name, auto (true if the name was made up), its code, and a command to run after it, or null. See CONTRACT.md.
