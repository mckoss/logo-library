logo-library

<logo-example>

A runnable, editable Logo program: Run, Revert Code, Copy, Open in Playground, a drawing speed, and a Then run command when it has one. Run opens a stage below it, with Snapshot and Make Recording. The program is the text of the <pre><code> inside, so it can be read and printed without the script. The lessons entry defines it. This page's markup:

<logo-example>
<pre><code>repeat 36 [fd 120 rt 170]</code></pre>
</logo-example>

<logo-example try="square 100" name="Square">
<pre><code>to square :size
  repeat 4 [fd :size rt 90]
end</code></pre>
</logo-example>

<logo-example try="flower 12" view="400x400" name="Flower">
<pre><code>to petal :size
  repeat 2 [repeat 9 [fd :size rt 10] rt 90]
end

to flower :size
  repeat 12 [petal :size rt 30]
end</code></pre>
</logo-example>

try is the command to run after the program, view the stage's size in turtle steps (600x360 if not given), and name the program's name in the Playground and in snapshot file names. See CONTRACT.md.

repeat 36 [fd 120 rt 170]

end

A flower

to petal :size
  repeat 2 [repeat 9 [fd :size rt 10] rt 90]
end

to flower :size

end
