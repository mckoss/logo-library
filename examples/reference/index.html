<logo-reference>

The Logo language reference: every command, with a search box and examples that run when clicked. The reference itself is the package's, so the element has no content. The reference entry defines it. This page's markup:

<logo-reference hint="Type a few letters, like fo for forward."></logo-reference>

hint is the line under the search box. A page holds one reference at most (the Playground has one too). Its link to the music player is ../player/, relative to this page. See CONTRACT.md.
